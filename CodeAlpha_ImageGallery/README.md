# **Image Gallery**
A responsive image gallery built with HTML, CSS, and vanilla JavaScript, created as part of the _CodeAlpha Frontend Development Internship_.

## **Features**
+ Dynamic category layout — Nature, People, and Streets, each with its own column
+ Filtering — switch between categories from the navigation (header and footer), with smooth fade transitions
+ Lightbox view — click any image to open it full-screen with:
  1. Next / Previous navigation (loops around at the start/end)
  2. Filter-aware navigation (only cycles through the currently selected category)
  3. Keyboard support (← → to navigate, Esc to close)
  4. Click outside the image to close

+ Fully responsive — adapts to desktop, tablet, and mobile screens
+ Hover effects and smooth CSS transitions throughout
+ 
## **Tech Stack**
+ HTML5
+ CSS3 (Flexbox, CSS Grid, transitions)
+ Vanilla JavaScript (DOM manipulation, no frameworks/libraries)
+ Google Fonts (Amatic SC)
