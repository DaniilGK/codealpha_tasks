# **Portfolio**
A personal one-page portfolio site built with HTML, SCSS, and vanilla JavaScript, showcasing projects, skills, and experience.

## **Features**
+ Single-page layout with smooth anchor navigation — About, Projects, Skills, Resume, Contact
+ Projects section as a horizontal slider with scroll-snap, active-card highlighting, and animated GIF previews of each project
+ Skills grid with inline SVG icons (HTML5, CSS3, Sass, JavaScript, Git, Node.js, Firebase, and more)
+ Resume section with downloadable CV/Cover Letter (PDF) and a timeline of education and courses
+ Scroll-triggered fade-in animations for each section, powered by the IntersectionObserver API
+ Global mouse-parallax background — layered shapes respond to cursor movement
+ Section-based scroll-parallax backgrounds with smooth gradient blending between sections
+ Nav links highlight automatically to reflect the section currently in view while scrolling
+ Fully responsive — adapts to desktop, tablet, and mobile screens

## **Tech Stack**
+ HTML5
+ CSS3 / SCSS (Flexbox, Grid, custom properties, mixins, transitions)
+ Vanilla JavaScript (IntersectionObserver, scroll/pointer event handling, DOM manipulation, no frameworks/libraries)
+ Google Fonts (Poppins)
